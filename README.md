# 缇斯亚 · 重置版

第一阶段是独立的代码骨架与界面架构预览。预设基线采用 2026-10-31 确认的 v10 纯净占位符版与完整默认版，内容指纹登记在 `baseline.lock.json`。预设正文由本地文件导入，不随公共源码发布。

此项目从空仓库开始，旧项目只供按需查验。页面与服务分开；配置、表单和创世草稿通过同一个工作区存储接口保存。原有水相素材作为界面参考复用，其来源与指纹见 `docs/architecture.md`。

## 本地运行

使用现代浏览器打开静态服务提供的 `index.html`：

```sh
python3 -m http.server 8000
```

无需安装前端依赖。构建单文件阅读预览：

```sh
python3 tools/build.py
```

业务单元检查：

```sh
node --test tests/*.test.mjs
```

## 本阶段能力

- 手机尺寸优先的导航、会话双输入草稿、档案与表单编辑、偏好草稿、创世模块草稿。
- 场外事务、伏笔、倒计时、时间锚、生命线的独立入口和草稿记录。
- 浏览器本地保存、重新读取、导出；预设文件在本机核对 SHA-256。
- 接口边界：宿主保存/消息/生成、模型调用、自动填表与归档为后续适配点。

不将预览数据写进旧项目或宿主。页面中的保存只保存本机预览草稿；发送模型、推进故事、自动归档没有伪造实现。当前不提供可安装扩展包。

## 源码责任

| 路径 | 责任 |
|---|---|
| `src/catalog.mjs` | 68 个模块和 22 张表单字段注册 |
| `src/domain.mjs` | 工作区草稿及纯业务变换 |
| `src/storage.mjs` | 本机存取、错误和真实回读 |
| `src/preset.mjs` | 导入预设结构与基线指纹检查 |
| `src/host.mjs` | 宿主能力接口边界 |
| `src/render.mjs` | 只读页面渲染 |
| `src/app.mjs` | 页面事件与服务调用 |
| `styles.css` | 水相主题、手机与宽屏布局 |

界面结构通过评审后，再按模块展开宿主与运行链路；全部系统功能仍以完整设计蓝图为准。
