# 缇斯亚 · 重置版

会话与叙事接入版 `0.1.0`。这是重置版的独立安装仓库，已包含完整默认预设、会话界面、叙事配置、场外交流、选段改写及回合记忆引擎接口。

当前适配 **TauriTavern** 的 `ChatSurface v1`、`MessageFormatter` 和 `extension.store`。已验证的宿主为 Linux TauriTavern 2.4.0、酒馆助手 4.11.3；不能据此保证普通 SillyTavern 或旧版宿主兼容。

## 安装插件与预设

1. 在 TauriTavern 的「扩展 → 安装扩展」粘贴下面的地址，然后重启宿主：

   ```text
   https://github.com/Tisyaofgit/-.git
   ```

2. 如已启用旧缇斯亚前端，先停用旧版，避免两个界面同时接管消息。首次启动会启用宿主聊天虚拟化并自动刷新一次。
3. 打开缇斯亚「预设」，点 **「安装本包完整默认预设」**，选用 **「缇斯亚 · 当前完整默认」**。预设文件已经内置，无需另行下载或复制提示词；安装插件不会自动切换预设。
4. 在宿主中配置自己的模型连接，选择角色卡与用户角色，再开始聊天。变量/MVU 功能仍使用酒馆助手及原卡脚本。插件会关闭酒馆助手的消息前端渲染和宿主代码预览，以由同一前端渲染消息；不会关闭助手的变量脚本能力。

## 启动完整表单与记忆结算

**安装前端插件不等于启动引擎。** 表单计算、回合记忆同步、材料注入需要本仓库的 Python 伴随进程。仓库已包含引擎代码与空白工作簿；不含用户会话、账户或模型密钥。

电脑安装 Python 3.10 或以上与 Node.js，然后下载本仓库 ZIP 并解压。在解压目录中：

- Windows：双击 `start-engine.bat`。
- macOS / Linux：运行 `sh start-engine.sh`。

保持启动窗口打开。电脑本机使用时，在酒馆扩展设置中的「缇斯亚 · 引擎与回合记忆」检查引擎地址 `http://127.0.0.1:8765`，点「检查连接」，为新聊天点「绑定空白引擎」，或导入已有引擎备份。旧聊天应导入自己的备份，不必新建空白状态。

手机使用 TauriTavern 时，完整引擎目前仍需在同一局域网的电脑启动。使用 `sh start-engine.sh --host 0.0.0.0`（Windows 用 `start-engine.bat --host 0.0.0.0`），手机插件中的引擎地址改为 `http://电脑的局域网IP:8765`，并允许电脑防火墙的局域网连接。手机里的 `127.0.0.1` 指手机本身。这里只说明连接方式，**Android 尚未实机验证**。

如果提示 `ORIGIN_NOT_ALLOWED`，启动时追加 `--allow-origin` 和当前宿主页面的实际源地址，不要将报错当作已连接。
